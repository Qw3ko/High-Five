# High five (онлайн-платформа для выявления профессионального выгорания) React, TypeScript, Vite.JS

Проект выполнен в рамках стажировки в Clovery.

Ввиду того, что серверная часть больше не работает, этот проект является примером вёрстки. Реализована только десктопная версия, так как для мобильной версии дизайна не было.

Это онлайн-платформа, направленная на отслеживание выгорания у персонала.

Для захода на сервис используйте логин admin и пароль 123456.

На сайте реализованы такие возможности 
1) Пройти опрос для выявления выгорания
2) Чат с HR
3) Полноценные роли сотрудника и HR
4) Статистика по выгоранию среди сотрудников
5) Авторизация
